# 笺 · 网易云桌面歌词

贴在 Windows 桌面上的网易云同步小组件：封面、歌词、热评、进度条与 DDL 月历。

## 环境要求

- Windows 10/11
- [Node.js](https://nodejs.org/)（建议 LTS）
- 本机已安装并登录 [网易云音乐](https://music.163.com/) 客户端
- Python 3（用于暂停 / 上一首 / 下一首热键控制，可选但推荐）

## 安装与启动

在项目文件夹打开终端，执行：

```bash
npm install
npm start
```

启动后请先打开网易云并开始播放，桌面才会同步当前歌曲。

## 使用说明（简要）

- 封面下方可拖动进度条（需能定位网易云进度条时）
- 点击封面可暂停 / 播放；切歌走网易云全局热键，尽量不把网易云窗口顶到前面
- 右键封面可设置壁纸等
- 个人 DDL、听歌统计保存在本地 `data/`，不会随仓库同步

## 说明

进度主要来自网易云本地日志旁路同步，偶有零点几秒偏差属正常现象。

## 歌词简繁说明

由于本人听港台歌手比较多，所以歌词默认统一转成繁体（台湾正体）显示；只有以下几位特定歌手的歌词设置成了简体：

- 许嵩
- 王菲
- 窦靖童
- 陈粒
- 陈婧霏

为了省事，除上述歌手外的所有歌手歌词都直接设置成了繁体——因为要自动识别一位歌手是内地还是港台，是一个很大的工程。如果想让其他歌手显示简体，可以在 `src/netease.js` 的 `SIMPLIFIED_ARTISTS` 列表里自行添加。
